# Build log

> **2026-10-22:** the Expo app described in the first half of this log was
> removed at the user's request (iOS only). Its notes stay for history; the
> current app is in the "Native iOS" section.

App: Expo SDK 58 (React Native 0.88), expo-router, TypeScript. Working name
"Cat Logic" until `/replica-brand`. Parity after this build: 88.4, must-haves
12 of 13 (cat art is a placeholder).

How to check it:

```bash
npm test                                          # engine + game rules (12 tests)
npm run typecheck
npx expo export --platform web && npx tsx scripts/screens.ts   # plays every flow, screenshots, fails on console errors
npx expo start                                    # run it on a phone with a development build
```

## Changes from architecture.md

- **Styling:** a generated `src/theme/tokens.ts` with StyleSheet, instead of
  NativeWind. Same tokens, one less build step. `build_tokens.py` writes it.
- **Storage:** AsyncStorage behind the `GameRepo` interface
  (`src/data/types.ts`), not expo-sqlite yet. Same function signatures, so
  `/replica-backend` swaps it without touching screens.
- **Leaderboard:** sample data behind `LeaderboardApi`, and the screen says so.
- **Daily:** generated on the device as planned. 10×10 generation measured at
  36 ms median and 262 ms worst case (Node), under the 300 ms budget.

## Native iOS (SwiftUI), 2026-10-22

Built on request as a native app in `ios-native/` (SwiftUI, iOS 17+). The
Expo app was later removed. Backend (Game Center) notes: `replica/backend.md`.

- **CatLogicKit** (Swift package): the engine, game rules, saving
  (`FileStore`, one JSON file in Application Support), the sample leaderboard
  and the screen models (`PuzzleSession`, `HomeModel`, `LeaderboardModel`).
  29 tests pass on Linux (22 at first, 7 more for the Game Center rules) (Swift 6.1.3 in Docker). They show the Swift engine
  matches the TypeScript bit for bit: the same random numbers, all 8 pinned
  daily boards, and 60 levels regenerated from their seeds. The slowest daily
  of a week generates in 8 ms (release build).
- **App** (SwiftUI): every screen from the web build, using SF Symbols
  instead of Lucide, a native navigation stack, sheets for hint/fail/win, and
  `sensoryFeedback` for haptics. Every cell has a VoiceOver label plus "Place
  cat" and "Clear" actions.
- **Project:** `CatLogic.xcodeproj`, generated by XcodeGen 2.46.0 from
  `project.yml`.
