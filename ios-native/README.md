# Napspot for iOS (SwiftUI)

Native iOS 17+ app. The daily leaderboard is Game Center; setup steps are in
`replica/backend.md`.

```
ios-native/
  CatLogic.xcodeproj   generated by XcodeGen from project.yml; open this
  project.yml          the project spec (regenerate after adding files)
  CatLogic/            the app: SwiftUI views only
    Screens/           Home, Levels, Puzzle (board, sheets), Leaderboard, Settings, HowToPlay, Design
    Components/        BoardView, buttons, cat, lives
    Theme/Tokens.swift generated from replica/design/tokens.json (npm run tokens)
    Resources/Fonts/   Nunito (SIL OFL, see OFL.txt)
  CatLogicKit/         Swift package: engine, game rules, saving, leaderboard
                       interface and screen models. Tested with `swift test`.
```

## Run it

1. Xcode 16 or newer on a Mac.
2. `open ios-native/CatLogic.xcodeproj`
3. Signing & Capabilities: pick your team, and change the bundle id
   (`com.example.napspot`) to one you own.
4. Run on a simulator or a phone.

After adding or removing Swift files: `brew install xcodegen && cd ios-native && xcodegen generate`.

## Test it

```bash
cd ios-native/CatLogicKit && swift test             # on a Mac
# or anywhere with Docker:
docker run --rm -v "$PWD":/pkg -w /pkg swift:6.1-noble swift test
```

The tests check that the Swift engine makes exactly the same daily puzzles
and levels as the TypeScript reference (`engine/`). If you change the
generator, change both, bump `generatorVersion`, and re-pin the golden boards.

Without the App Store Connect leaderboard set up, run with the launch argument
`-sampleLeaderboard` to see sample players.
